---
name: planning
description: Decompose business work into governed steps and recommend the next action.
allowed-tools:
  - Read
  - Grep
---

Use this skill when a user needs a decomposed plan, a route recommendation, or a controlled next step.

Rules:
- Keep the plan grounded in approved assets.
- Separate user intent, constraints, and tool-ready steps.
- Prefer concise, auditable step lists over free-form reasoning.
- If a policy or required tool is missing, stop and report the gap.
