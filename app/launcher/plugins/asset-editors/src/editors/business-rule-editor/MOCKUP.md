      "columns": 3,
      "elements": [
        { "type": "Control", "scope": "#/properties/rule_id" },

## Tab Flow

1. **Structured Editor** → JSON Forms with GridLayout
2. **Raw Source** → JSON textarea editor
3. **History** → Lifecycle snapshot and validation status
