## GridLayout Structure

```json
{
  "type": "GridLayout",
  "elements": [
    {
      "type": "GridLayout",
      "columns": 3,
      "elements": [
        { "type": "Control", "scope": "#/properties/entity_id" },
        { "type": "Control", "scope": "#/properties/entity_name" },
        { "type": "Control", "scope": "#/properties/domain" }
      ]
    },
    { "type": "Control", "scope": "#/properties/description" },
    { "type": "Control", "scope": "#/properties/aliases" },
    { "type": "Control", "scope": "#/properties/attributes" },
    { "type": "Control", "scope": "#/properties/relations" }
  ]
}
```

## Tab Flow

1. **Structured Editor** → JSON Forms with GridLayout
2. **Raw Source** → JSON textarea editor
3. **Relationships** → Read-only relation preview
4. **History** → Lifecycle snapshot and validation status
