# Wiki de Soporte Interno

## Preguntas frecuentes de clientes

Pregunta: Que documentos necesito para abrir una cuenta de ahorro?
Respuesta esperada: identificacion oficial, comprobante de domicilio y datos
fiscales si aplican. No iniciar proceso si el usuario solo pregunta requisitos.

Pregunta: Como solicito un prestamo personal?
Respuesta esperada: explicar que se requieren monto, plazo, finalidad,
evidencia de ingresos y documentos. Si el usuario pide guia, iniciar caso
guiado. Si pide ejecutar, crear solicitud solo cuando los datos esten completos.

Pregunta: Que datos necesito para una transferencia?
Respuesta esperada: cuenta origen, beneficiario o CBU, monto y concepto.

Pregunta: Como presento un reclamo?
Respuesta esperada: pedir motivo, referencia, fecha, importe y evidencia.

## Guia para agentes

Si el cliente usa frases de consulta como "que necesito", "por que", "cual es",
"como funciona" o "que significa", normalmente se trata de una respuesta
informativa.

Si el cliente usa frases como "ayudame", "guiame", "paso a paso", "quiero
iniciar" o "vamos a empezar", normalmente se trata de un caso guiado.

Si el cliente usa frases como "ejecuta", "crea ahora", "procesa", "confirma",
"envia", "realiza" o "registra", normalmente se trata de ejecucion de proceso.

Estas pistas no son etiquetas definitivas. El analizador semantico debe
considerar contexto, datos presentes, permisos, reglas y si hay un proceso
ejecutable relacionado.

## Frases ambiguas

"Quiero un prestamo" puede significar consulta, caso guiado o ejecucion. Si no
hay datos completos ni confirmacion explicita, preguntar si desea informacion,
guia paso a paso o enviar una solicitud.

"Necesito hacer una transferencia" puede ser caso guiado. "Ejecuta la
transferencia con estos datos" es ejecucion si los datos estan completos.

"Tengo un cargo desconocido" puede ser consulta o inicio de reclamo. Pedir
aclaracion si no hay intencion explicita.
