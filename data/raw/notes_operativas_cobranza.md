# Notas operativas de cobranza

Estas notas contienen fragmentos de procesos, criterios de atencion y
situaciones de seguimiento.

## Casos frecuentes

- cliente con pago retrasado y buena disposicion
- cliente con promesa de pago
- cliente con refinanciamiento solicitado
- cliente con cambio de fecha de corte
- cliente con exencion temporal por desempleo

## Acciones sugeridas

1. Confirmar saldo y ultima fecha de pago.
2. Registrar motivo de contacto.
3. Definir si requiere promesa, escalacion o seguimiento.
4. Enviar recordatorio si el caso permanece abierto.

## Proceso

El analista de cobranza consulta al sistema, valida la situacion y luego
documenta el siguiente paso. Si el caso ya tiene una regla activa, no se
repite la solicitud a un usuario sin necesidad.
