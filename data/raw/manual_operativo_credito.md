# Manual operativo de credito

El objetivo de este manual es describir tareas operativas de prestamos, pagos,
refinanciamiento y atencion al cliente.

## Capitulo 1: Analisis inicial

1. Revisar el saldo actual del prestamo.
2. Confirmar si el cliente tiene un pago automatico activo.
3. Consultar si hay mora o pagos atrasados.
4. Identificar si el caso corresponde a refinanciamiento o reestructuracion.

## Capitulo 2: Flujo de atencion

Cuando el cliente desea cambiar la cuota:
- abrir expediente
- validar identidad
- explicar opciones de refinanciamiento
- registrar el resultado de la interaccion

## Capitulo 3: Reglas del equipo

- No prometer aprobacion antes de la validacion de credito.
- No crear una instruccion de backend como tarea humana.
- Toda consulta a sistemas debe quedar registrada.
- Toda decision extraordinaria debe referenciar aprobacion.

## Capitulo 4: Observaciones

En algunas sucursales se usa el termino "renegociacion", pero el proceso
interno lo trata como refinanciamiento cuando el saldo se mantiene activo.
